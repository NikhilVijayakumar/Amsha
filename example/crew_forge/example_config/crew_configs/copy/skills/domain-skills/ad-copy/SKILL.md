# Ad Copy Writing

Follow these conventions for every ad-copy task:

1. Lead with a benefit, not a feature.
2. Keep the headline under 60 characters.
3. Use a single clear call to action.
4. Match the tone to the target audience; be concise.

If the task asks for JSON output, return an array of ad variations, each with
`id`, `style`, `headline`, `body_text`, `cta`, and `visual_suggestion`.
